# 数据说明

三份快照，都只读、都是纯 JSON，不参与运行时加载（内置题库已内嵌进用户脚本）。

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| `papers-raw.json` | 94 门课逐门下发的原始试卷，含课程名与课程编码 | 470 题 |
| `questions-unique.json` | 按题干去重后的题目池 | 469 题 |
| `bank-seed.json` | 人工判定过答案的条目 | 442 条（94.2%） |

三者关系：`papers-raw` → 去重 → `questions-unique` → 判答案 → `bank-seed` → 内嵌进脚本。

## 字段

`papers-raw.json`：

```json
{
  "1246": {
    "name": "《习近平关于社会主义社会建设论述》（上）",
    "code": "GS202605001.mp4",
    "questions": [{ "qid": "9163", "type": "single", "q": "题干", "opts": ["选项A", "选项B"] }]
  }
}
```

`bank-seed.json` 是紧凑四元组数组，字段顺序固定：

```json
["single", "题干", ["答案文本"], ["A"]]
```

`type` 取 `single` / `multi` / `judge`。判断题的答案是 `["对"]` 或 `["错"]`，不用 `1` / `0`，避免导出后看不懂。

## 为什么只收录 94.2%

未收录的 27 条分两类：

1. **甘肃地方性数据题**（马跑泉灌溉井人口、宝兰客专禁采区耕地面积、结对帮扶人数、庄浪梯田人物与土方量等），无法脱离课程视频核实。
2. **题干本身有缺陷**，例如「下列哪项不属于……（ ）」但四个选项都成立，或单选题实际有多个正确答案。

原则是**宁缺勿错**：留空只会跳过该题，写错会直接填错并拉低整卷得分。

## 来源与边界

题库来自使用者本人有权访问的培训课程试卷，逐题人工判定答案。没有抓取任何需要额外权限的内容，也不包含姓名、单位、账号等个人信息。

- 题目与课程内容的著作权归原平台及原作者。
- 本仓库仅收录题干与选项文本，用于本地作答辅助，不做二次分发或商业使用。
- 权利人如有异议，开 issue 说明即可，相应条目会立即移除。

`questions-unique.json` 与 `papers-raw.json` 可以直接删除——脚本只依赖内嵌的 `SEED_RAW`，删掉数据文件不影响运行，但 `npm test` 会因缺少比对基准而失败。
